\subsection*{Задание 3:}
\lstinputlisting[caption={Исходный код программы (C)}]{3.c}
\noindent \indent
Суть данного задания - проверить каждое $a_i$ есть ли для него такая комбинация замены префикса(мин)/суффикса(макс),
чтобы оно заполнило весь массив. Для решения этого задания вводятся массивы $pm$ и $sm$
в которых хрянятся минимальные числа слева от $a_i$ и максимальные справа от $a_i$ соответсвенно.
Если $a_i$ меньше чем числа слева или больше чем числа справа - то выводим 1, иначе 0.

\subsection*{Задание 4:}
\lstinputlisting[caption={Исходный код программы (C)}]{4.c}
\noindent \indent
Суть данного задания - вычислить размер фотографии $w \cdot h$, где $w$ - сумма $w_i$, а $h$ - максимальное $h_i$
для каждого друга, так как один из друзей фотографирует остальных. Для решения задачи суммируем w, находим максимальный
и следующий после него $h$ и вычисляем размер, вычитая из суммы $w_i$ и умножаешь на максимальное (или на следующее максимальное).

\subsection*{Задание 5:}
\lstinputlisting[caption={Исходный код программы (Python)}]{5.py}
\noindent \indent
Суть данного задания - найти кол-во пар элементов, которые можно удалить из массива чтобы среднее арифметическое не поменялось.
Для реализации алгоритма находим целевую сумму чисел, если сумма вещественная - то из входных данных мы не найдём подходящей пары.
В цикле проходим по элементам и находим элемент, который нам нужен $need = target - x$, добавляем к счётчику число из словаря $ans += count[need]$,
и увеличиваем значение текущего эл. в словаре $count[x] += 1$
