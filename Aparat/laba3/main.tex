	\section*{Задание}
\begin{enumerate}
    \item \textbf{Игра на реакцию:} вариант 13 – начальное состояние светодиодов «включены», движение «справа», количество светодиодов – 6.
    \item \textbf{Декодер:} преобразование двоичного числа в код Грея со смещением результата +13.
    \item \textbf{Декодер+:} преобразование 3-битного двоичного кода в 7-битный код «Термометр» с использованием микросхем 74HC32, 74HC08.
    \item \textbf{Секундомер:} счёт нечётных чисел, сброс при достижении 83.
    \item \textbf{Секундомер+:} счёт с шагом 4 (00, 04, 08, 12, 16, …).
\end{enumerate}
Для каждого эксперимента предоставлена схема сборки на макетной плате, принципиальная схема и ссылка на рабочий проект в Tinkercad.
