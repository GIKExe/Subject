Ты – Senior Frontend
Developer, специализирующийся на визуализации данных. Твоя задача – по-
мочь разработать одностраничное веб-приложение «Визуализатор нормаль-
ного распределения». Пользователь вводит среднее значение (µ) и стандарт-
ное отклонение (σ). После нажатия кнопки приложение генерирует 10000
случайных чисел, распределённых по нормальному закону с этими параметра-
ми, и строит гистограмму (количество столбцов – 30–40), которая должна
визуально напоминать колоколообразную кривую. Для построения графиков
используй библиотеку Chart.js. Реализуй валидацию ввода: µ – любое число, σ
> 0, поля не должны быть пустыми. При ошибке выводи понятное сообще-
ние. Интерфейс должен быть современным, адаптивным, с тёмной или свет-
лой темой на выбор. В ответе выдай 3 блока кода последовательно: HTML, CSS, JS. 

Во-первых:
Сгенерируй чистый HTML-код для приложения визуализатора
нормального распределения. Используй семантические теги (<header>, <main>,
<section>, <footer>). Добавь поля ввода для µ и σ, кнопку «Построить гра-
фик», а также контейнер <canvas> для графика и блок для вывода сообщений
об ошибках. Все интерактивные элементы должны иметь уникальные id. Не
добавляй CSS и JS, только структуру. Используй id элементов: mu-input, sigma-input, generate-btn, distribution-chart, error-message.

Во-вторых:
Сгенерируй CSS для оформления: тёмная тема (фон #1e1e2f,
карточка с полями ввода – полупрозрачный фон, зелёные акценты), адаптив-
ная вёрстка с использованием Flexbox/Grid, стили для кнопки, полей ввода,
canvas. Учти, что на мобильных устройствах график должен масштабиро-
ваться.

В третьих:
Напиши JavaScript-код, который:
• По нажатию на кнопку считывает µ и σ, проверяет их (σ > 0, оба поля
не пустые). При ошибке – выводит сообщение в блок id="error-message".
• Генерирует 10000 случайных чисел, распределённых по нормальному за-
кону, используя преобразование Бокса — Мюллера.
• Строит гистограмму с 40 столбцами (bins) на основе сгенерированных
данных.
• Отображает гистограмму с помощью Chart.js, накладывая теоретиче-
скую кривую нормального распределения для сравнения (опционально, но
желательно).
• Обрабатывает случай, когда старый график уже существует (уничто-
жать предыдущий экземпляр Chart).
• Используй id элементов: mu-input, sigma-input, generate-btn, distribution-
chart, error-message. 

Добавь в JavaScript дополнительную защиту: если binWidth ока-
зывается равным 0 (все сгенерированные числа совпали), установи binWidth
= 1 и обработай ошибку через консоль. Также добавь ограничение на слиш-
ком большие значения σ (например, если σ > 1000, выводи предупреждение,
что гистограмма может быть неинформативной). И очищай сообщение об
ошибке перед новой генерацией.
