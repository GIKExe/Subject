ВАРИАНТ 20: Водоподготовка
============================================================
Описание: Датчики очистных сооружений: турбидность, pH, остаточный хлор, расход воды. Контроль гарантирует соответствие санитарным нормам.

 Поля:
  • ts (int32): время замера
  • filter_id (int16): ID фильтра
  • turb (float32): турбидность, NTU
  • ph (float32): кислотность воды
  • cl (float32): остаточный хлор, мг/л
  • flow (float32): расход воды, м³/ч

Очистка: turb < 0 → 0. cl < 0 → 0. ph clip по [6.5, 8.5].
Пояснение: Турбидность и хлор не могут быть отрицательными → 0. pH питьевой воды ограничен санитарными нормами 6.5–8.5 → обрежьте.

Группировка: По filter_id. Средний turb, макс flow.
Пояснение: Для каждого фильтра посчитайте среднюю мутность (эффективность очистки) и максимальный пропуск (нагрузка на систему).

Окно: k=35. Moving avg turb. np.diff(flow) → изменение расхода.
Пояснение: Сглаженная турбидность покажет стабильность качества воды. Изменения расхода между замерами укажут на работу насосов или засорение.

Акцент: Обратная зависимость чистоты и turb, маски без взаимного влияния.
Пояснение: Чем ниже турбидность, тем чище вода. При фильтрации аномалий обрабатывайте каждый параметр независимо, не связывая их логикой.
============================================================
