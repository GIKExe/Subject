\section*{Цель работы}
Освоить методы векторизованной предобработки данных с использованием библиотеки NumPy. Получить навыки работы с структурированными массивами, булевыми масками, групповой агрегацией и созданием производных признаков для задач промышленного мониторинга.

\section*{Постановка задачи}
\indent
Необходимо выполнить предобработку данных с датчиков очистных сооружений (вариант~20). Исходный файл \texttt{data.csv} содержит следующие поля:
\begin{itemize}
	\item \texttt{ts} (int32) — время замера;
	\item \texttt{filter\_id} (int16) — идентификатор фильтра;
	\item \texttt{turb} (float32) — турбидность, NTU;
	\item \texttt{ph} (float32) — кислотность воды;
	\item \texttt{cl} (float32) — остаточный хлор, мг/л;
	\item \texttt{flow} (float32) — расход воды, м³/ч.
\end{itemize}

\noindent
Требуется реализовать 10 этапов обработки:
\begin{enumerate}
	\item Загрузка данных в структурированный массив \texttt{numpy.dtype}, оценка объёма памяти, подсчёт NaN/Inf.
	\item Векторизованная фильтрация аномалий: \texttt{turb < 0 → 0}, \texttt{cl < 0 → 0}, \texttt{ph → clip[6.5, 8.5]}.
	\item Группировка по \texttt{filter\_id}, расчёт статистик и Z-score нормализация \texttt{turb} внутри групп.
	\item Скользящее среднее для \texttt{turb} (окно $k=35$) через кумулятивную сумму, вычисление \texttt{np.diff(flow)}.
	\item Создание производных признаков: индекс чистоты и эффективность хлорирования.
	\item Условная агрегация: статистики по \texttt{turb} для записей с расходом выше среднего.
	\item Лаговые признаки (lag=1) для \texttt{turb}, анализ распределения знаков разницы.
	\item Робастная замена выбросов по методу IQR внутри каждой группы фильтров.
	\item Проверка согласованности данных по предметным правилам, замена некорректных значений.
	\item Частотный анализ категориального поля \texttt{filter\_id}, объединение редких категорий.
\end{enumerate}

\indent
\textbf{Ограничения:} запрещено использование циклов \texttt{for} по строкам исходного массива. Все операции должны выполняться векторизованно через булевы маски, \texttt{np.where}, \texttt{np.clip}, \texttt{np.unique}.

\subsection*{Этап 1: Загрузка и подготовка типов}
Для чтения файла использована функция \texttt{np.genfromtxt} с явно заданным структурированным типом данных:
\begin{lstlisting}
dtype = np.dtype([
	('ts', np.int32), ('filter_id', np.int16),
	('turb', np.float32), ('ph', np.float32),
	('cl', np.float32), ('flow', np.float32)
])
data = np.genfromtxt('/content/data.csv', delimiter=',', 
					 skip_header=1, dtype=dtype, encoding='utf-8')
\end{lstlisting}
Объём памяти рассчитан через атрибут \texttt{nbytes}, подсчёт некорректных значений выполнен через \texttt{np.isfinite}.

\subsection*{Этап 2: Векторизованная очистка}
Аномалии обнаружены составной булевой маской:
\begin{lstlisting}
mask_anomaly = (data['turb'] < 0) | (data['cl'] < 0) | \
			   (data['ph'] < 6.5) | (data['ph'] > 8.5) | \
			   ~np.isfinite(data['turb']) | ~np.isfinite(data['cl'])
\end{lstlisting}
Очистка выполнена без циклов:
\begin{lstlisting}
data['turb'] = np.where(data['turb'] < 0, 0.0, data['turb'])
data['cl']   = np.where(data['cl'] < 0, 0.0, data['cl'])
data['ph']   = np.clip(data['ph'], 6.5, 8.5)
\end{lstlisting}

\subsection*{Этап 3: Группировка и нормализация}
Группировка реализована через \texttt{np.unique} с циклом по уникальным значениям \texttt{filter\_id} (цикл по группам разрешён). Z-score нормализация:
\begin{equation}
z = \frac{x - \mu_{group}}{\sigma_{group} + \varepsilon}, \quad \varepsilon = 10^{-8}
\end{equation}

\subsection*{Этап 4: Скользящее окно и разность}
Скользящее среднее вычислено за $O(N)$ через кумулятивную сумму:
\begin{lstlisting}
cs = np.cumsum(turb_arr)
mavg[k-1:] = (cs[k-1:] - np.concatenate(([0.0], cs[:-k]))) / k
\end{lstlisting}
Изменение расхода: \texttt{diff\_flow = np.insert(np.diff(data['flow']), 0, 0.0)}.

\subsection*{Этапы 5--10}
\begin{itemize}
	\item Производные признаки: \texttt{clean\_idx = 1.0 / (turb + 1e-8)}, \texttt{cl\_eff = cl / (flow + 1e-8)}.
	\item Условная агрегация: c. маска \texttt{(filter\_id == fid) \& (flow > mean\_flow)}.
	\item Лаговые признаки: \texttt{lag1 = np.roll(turb, 1)}, анализ через \texttt{np.sign} и \texttt{np.bincount}.
	\item IQR-замена: границы $[Q_1 - 1.5\cdot IQR, Q_3 + 1.5\cdot IQR]$ вычислены внутри групп.
	\item Проверка логики: предметные правила для питьевой воды, замена через \texttt{np.where}.
	\item Сжатие категорий: редкие \texttt{filter\_id} (<1\% вхождений) объединены в \texttt{OTHER} (код~0).
\end{itemize}

\section*{Выводы}
\indent
В ходе выполнения лабораторной работы были освоены методы векторизованной предобработки данных с использованием библиотеки NumPy. Ключевые результаты:
\begin{enumerate}
	\item Реализована полная обработка массива из 2 млн записей без циклов по строкам, что обеспечило высокую производительность.
	\item Применены предметно-ориентированные правила очистки: физические ограничения для турбидности и хлора, санитарные нормы для pH.
	\item Групповая нормализация и IQR-замена выбросов позволили учесть технологическую неоднородность оборудования.
	\item Временные признаки (скользящее среднее, лаги, разности) выявили устойчивые тренды качества воды и динамику работы насосов.
	\item Сжатие редких категорий предотвратило разреженность признакового пространства для последующего машинного обучения.
\end{enumerate}

\indent
Особенности предобработки данных водоподготовки:
\begin{itemize}
	\item Высокий уровень аппаратного шума требует агрессивной, но физически обоснованной фильтрации.
	\item Жёсткие санитарные нормативы (pH 6.5--8.5) диктуют обязательное клипирование, а не статистическую замену.
	\item Групповая обработка критически важна: разные фильтры имеют разную пропускную способность и степень износа.
	\item Векторизованные операции на базе NumPy позволяют обрабатывать миллионы записей за секунды, что необходимо для систем реального времени.
\end{itemize}

\indent
Итоговый массив \texttt{data\_final.npy} физически непротиворечив, нормализован и готов к решению прикладных задач: прогнозированию качества воды, мониторингу соответствия СанПиН, предиктивному обслуживанию оборудования.

\subsection*{Фрагмент: групповая IQR-замена (Этап 8)}
\begin{lstlisting}
turb_iqr = data_fe['turb'].copy()
for fid in unique_filt:
	m = data_fe['filter_id'] == fid
	vals = turb_iqr[m]
	q1, q3 = np.percentile(vals, [25, 75])
	iqr = q3 - q1
	lower, upper = q1 - 1.5*iqr, q3 + 1.5*iqr
	outlier = (vals < lower) | (vals > upper)
	if np.any(outlier):
		turb_iqr[m][outlier] = np.median(vals)
data_fe['turb'] = turb_iqr
\end{lstlisting}
